# Reference boundary

Status: **normative**. Applies to every contributor and every automated agent
working in this repository.

The reference project is
[`apple_watch_connector`](https://github.com/LordixDemon/apple_watch_connector),
materialised read-only at `reference/apple_watch_connector/` from material
already on this machine on 2026-11-22. It is quarantined data, not source.

## 1. One rule

> **The reference is an inventory of things to verify, never a source of code.**

Every file in `reference/` is untrusted until independently confirmed. Its
README claims are marketing until a physical observation, capture, or
independent test supports them. See
[inventory/reference-features.md](inventory/reference-features.md) for the
claim-by-claim inventory, including the reference's own admissions of
incomplete parity.

## 2. Access matrix

| Path | Lane A | Lane B | Lane C | CI |
| --- | --- | --- | --- | --- |
| `reference/**` | read (prose/fixtures) | **forbidden** | read (audit) | absent |
| `docs/cleanroom/spec/**` | write | read | read | read |
| `docs/cleanroom/inventory/**` | write | **forbidden** | read | read |
| `docs/cleanroom/audit/**` | read | **forbidden** | write | read |
| `app/**`, `core/**`, `agent/**`, `runtime/**`, `ffi/**` | **forbidden** | write | read | build |
| `third_party/apple/**` | propose | do not edit without review | approve | verify manifest |

Lane B means the production implementation lane: anyone or any agent writing
app, core, agent, runtime, payload, or FFI code. A Lane B agent must not list,
open, grep, diff, or hash files under `reference/`.

## 3. What Lane A may extract

Allowed, and recorded in the spec with a pointer to the README/doc section:

- layer and protocol names observable on a watch the operator owns;
- message sequences and field meanings;
- state machines, checkpoints, retry and error behaviour;
- command/response inventories (what the watch expects, not how the reference
  named its methods);
- fixture contents that are protocol captures, described as vectors;
- the reference's list of Apple-owned assets, as an inventory to *avoid*.

Not allowed:

- copying source, comments, identifiers, string tables, test names, assets, or
  generated code into a spec;
- writing "implementation guidance" that is a paraphrase of a reference
  function, line by line;
- treating a README claim as a verified fact.

## 4. What Lane B receives

Only:

1. the Lane A spec;
2. the Open Crown design system and product requirements;
3. this boundary and the provenance policy.

Lane B may not receive: a reference checkout, screenshots of its source, its
class/type/method names, its error strings, or a diff against it. If a Lane B
agent needs a protocol fact that the spec does not contain, it stops and asks
Lane A for a spec amendment. It does not look it up in the reference.

## 5. Banned identifiers

Lane C maintains
[`docs/cleanroom/audit/banned-identifiers.txt`](audit/banned-identifiers.txt)
from a symbol inventory of the reference. The file is generated by a Lane C
tool against the reference tree and is not committed with source excerpts. A
match in product code is a finding, not automatically a violation: public
protocol terms and generic Android/Rust/Kotlin names are allowlisted. The
initial list is built in Phase 0; until it exists, Lane C uses the structural
comparison in the similarity plan.

## 6. Build independence

Hard requirement, checked at every phase gate and in CI when available:

```sh
# from a clean checkout with no reference directory
test ! -e reference
./gradlew :app:assembleDebug :app:testDebugUnitTest
cargo test --workspace
```

Additionally:

```sh
git grep -n 'reference/apple_watch_connector' -- . ':!docs' ':!README.md'
# must be empty
git grep -n 'apple_watch_connector' -- app core agent runtime ffi payloads
# must be empty
```

The owner's machine may keep `reference/` for Lane A/C. The release build, the
CI cache, and the product APK never include it.

## 7. Similarity review

Follow [inventory/similarity-plan.md](inventory/similarity-plan.md). At each
phase gate Lane C records in `docs/cleanroom/audit/phase-<n>-similarity.md`:

- files reviewed;
- method (token n-gram, structural, identifier, comment/string);
- findings with severity;
- disposition (clear, rename, rewrite, remove);
- reviewer and date.

A finding that cannot be cleared blocks the phase.

## 8. Apple-origin material

`reference/` contains watch-face containers, swatch images, optical-pairing
imagery, app icons, and Flutter/iOS artwork. None of it enters this repository.
Apple-owned material is not licensed for redistribution by this project. If a
genuine Apple-owned, redistributable artifact is ever needed:

```text
third_party/apple/<name>/
  SOURCE.md      # URL, retrieval date, what it is
  LICENSE        # the actual redistribution terms, or a citation
  SHA256SUMS     # hash of every file
  PURPOSE.md     # why an original equivalent is not used
```

The default decision is to write an original equivalent.

## 9. Escalation

If a requirement cannot be implemented without reference source:

1. Stop. Do not approximate from memory of the reference.
2. Open a blocker in [BLOCKERS.md](BLOCKERS.md) with the spec gap named.
3. Ask Lane A for a spec derived from captures, public material, or physical
   observation.
4. If the spec cannot be obtained lawfully, the feature is blocked, not faked.
